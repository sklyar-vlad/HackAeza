# HackAeza

Интерфейс анализа рисков непродления услуг. React + TypeScript, оформление в стиле Aéza.

## Запуск макета

```bash
docker compose up -d --build --wait frontend
```

Открыть **http://localhost:3000**. Документация доступна через пункт «База знаний» и по адресу http://localhost:3000/docs/.
Порт интерфейса задаётся переменной `FRONTEND_PORT` (по умолчанию `3000`).

Экраны: обзор, клиенты, карточка клиента, настройки модели, источник данных и настройки интерфейса.
Работают поиск, сортировки, фильтрация по риску, пагинация, локальный предпросмотр коэффициентов, пересчёт,
импорт и проверка JSON, светлая/тёмная/системная тема. Начальные данные — `testdata/data.json` организаторов.

Это интерактивный **макет**, без подключения к бизнес-API и серверной авторизации. Расчёт выполняется в браузере,
импорт и настройки модели действуют до перезагрузки страницы. Тема сохраняется в браузере.
Большие ID и суммы, не представимые точно как JavaScript safe integer, макет отклоняет явно; серверный контракт использует int64.
Коэффициенты и пороги взяты из примеров текущего OpenAPI. Реализация промышленного Risk Engine остаётся задачей Go backend.

## Локальная разработка

```bash
cd frontend
npm ci
npm run dev
```

Для работы ссылки `/docs/` используйте Docker-вариант. Проверки:

```bash
npm run lint
npm run typecheck
npm run test:ci
npm run build
```

Контракт API: `docs/openapi.yaml`. Команда `docker compose up -d --build` также запускает существующий Go-сервер на порту 8081 и документацию на порту 8080.
